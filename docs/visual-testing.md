# 画面の回帰テスト

Playwright の Chromium で Expo の本番 Web 書き出しを表示し、390×844、320×740、390×640、1280×1000 の4サイズ・40テストを検証します。認証画面、規約の表示、メール確認、初回登録の全6ステップ、空のデッキ、証言のあるデッキ、カード詳細、装飾、プロフィール、設定、交換、つながり、自己PR、パスワード再設定を対象にします。

ヘッダー、チャレンジバナー、自己PRバナー、先頭と末尾のカードについて、元HTMLとの位置・寸法の差が1px以内であることも検証します。基準画像を更新しても、この照合は省略されません。

メールでの登録、同意、確認コードの入力、プロフィール保存、再読み込み、ログアウト、再設定メールのリンクからのパスワード変更、新しいパスワードでの再ログインも実際の UI と API で実行します。確認コードと再設定リンクはテスト専用の受信箱から取得します。変動する再送カウントダウンだけを確認画面の画像比較から除外します。

```sh
npm ci
npx playwright install chromium
npm run test:vrt
npm run test:vrt:report
```

Node 22.13以上と OpenSSL が必要です。9010・9012番ポートを使用します。テスト専用の証明書を生成し、ローカル HTTPS から実際の Workers を呼び出します。D1・R2 はテスト実行ごとに起動する独立したローカル環境です。メールとプッシュの外部送信は捕捉します。実際のAPIで登録・認証・交換・証言を作成するため、本番アプリの通信をモック成功応答に置き換えません。

基準画像は OS ごとに保存します。現在の基準画像は macOS 用です。別 OS の実行結果はフォント描画が異なるため、その環境で画像を確認してから追加してください。

```sh
# 変更内容を確認したうえで、明示的に基準画像を更新する
npm run test:vrt:update
git diff -- e2e/visual/baselines
```

認証画面、デッキ、カード詳細、装飾、交換、自己PRでは `design/flocka-v2-blue-prototype.html` を別ページで表示し、元デザインとの比較画像とピクセル差分の計測結果もレポートに添付します。参照ページの JSX・CSS・アセットは変更せず、外部スクリプトとフォントの読み込みだけローカルに置き換えます。参照画像との比較は差の調査用であり、回帰テストの成功だけでデザインの完全一致を意味するものではありません。OAuth の未設定状態など、実際の設定による表示差も確認対象です。

参照 HTML のサンプルには同じ相手からの複数の印象があります。本実装の「印象は交換相手ごとに1回」の制約を維持するため、テストの実データでは一つを場面のメモとして送っています。テスト専用の相手プロフィールも元デザインの名前・役割・アイコン・関心を実際の API で保存します。ブラウザごとにローカルのクライアントIPを分け、認証の回数制限を無効化せずに独立したテストを実行します。

実機の Safe Area、カメラ、BLE、OS の通知、OAuth の認証先、メール配信は、この Web VRT では検証されません。
